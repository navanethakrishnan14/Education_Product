# school_product
EduSphere split into four applications:
- `Platform_frontend/` — platform administration UI
- `Platform_Backend/` — platform API
- `Tenant_frontend/` — React + TypeScript school portal with role cards and login routes
- `Tenant_backend/` — Node.js + Express + TypeScript + PostgreSQL tenant-scoped login API

See the Tenant_frontend and Tenant_backend READMEs for local setup. Never commit secrets.
